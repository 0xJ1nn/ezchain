# Code of conduct

Be direct, be kind, be specific.

- Critique the change, not the person.
- No harassment, discrimination, or personal attacks.
- Disagreement is welcome; evidence is expected. "It works on my machine" is not evidence.
- Do not share another user's keys, addresses, balances or trading history.
- Security reports go through `SECURITY.md`.

Maintainers may edit, lock, or remove contributions that violate this code. Repeated
violations end participation.

This code applies in issues, PRs, discussions, and any project space.
