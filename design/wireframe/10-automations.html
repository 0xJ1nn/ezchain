Automation vs strategy

related, not the same layer
Automation — a declarative rule you compose here: trigger, conditions, bounded actions. The executor evaluates it; no code runs.
Strategy plugin — external code that emits trade intents. It needs granted permissions and a passed paper gate before live mode.
Runs asrule · executor
Firing unittrigger event
Can open positionsonly via strategy rule
Paper gate requiredno · paper by default
Both paths pass the same risk engine. An automation cannot raise a limit or bypass a cooldown.
