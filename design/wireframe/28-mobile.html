Responsive rules

< 768 px is a different layout, not a narrower one
WidthSidebarTilesTablesCritical actions
≥ 1440persistent 240px3 columnsfull tabletopbar kill + row actions
1101–1439240px2 columnsfull tabletopbar kill + row actions
769–1100240px expanded2–3 columnsfull table, scrollstopbar kill + row actions
≤ 768hidden · bottom nav1 columnscrollssticky mode + kill
Below 768 px the bottom nav is Home, Browse, Signals, Positions, More. Chain filter and sync move into More; search becomes a full-width field on its own row.

Thumb & one-hand rules

44minimum tap target in both axes; 8 px between targets
1tap opens the kill scope sheet (all / chain / wallet / strategy)
2taps maximum to arm a sell or write-off; second tap must be explicit
3/4primary actions live in the lower third, above the 54 px nav + safe area
Kill switch. Sticky in the top bar on every frame, 44 px tall, red only in LIVE. It never hides behind a menu, and closing the sheet does not cancel the arming state.
Swipe down dismisses the quote sheet. Hardware wallets hand off to the device app and return with a signature, not a second confirm dialog.
No hover-only affordances. Every tooltip (source, age, exact value) has a tap equivalent.
